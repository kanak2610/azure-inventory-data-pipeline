# Inventory & Supply Chain Data Pipeline

An end-to-end data pipeline that takes raw inventory/supplier/sales CSVs and turns them into clean, analytics-ready KPI tables — plus a dashboard to actually see them.

Built as **Raw → Bronze → Silver → Gold** (the standard Medallion Architecture), using Azure Databricks, ADLS Gen2, Delta Lake, and Power BI.

There are two versions of the code here:
- **`scripts/`** – a local pandas version of the whole pipeline. Runs on your laptop, no Azure needed. This is what you'll actually run.
- **`databricks_notebooks/`** – the real PySpark/Delta Lake version, meant to run on an actual Databricks workspace.

---

## Run it (VS Code)

1. Open the `project/` folder in VS Code.
2. Open a terminal (`` Ctrl+` ``).
3. Set up a venv and install pandas:
```bash
   python -m venv .venv
   .venv\Scripts\activate      # Windows
   # source .venv/bin/activate   # macOS/Linux

   pip install pandas
```
4. Run everything:
```bash
   cd scripts
   python 00_run_pipeline.py
```

That's it — one command runs all 5 steps (raw data → bronze → silver → gold → dashboard), and your browser pops open at the end showing the finished dashboard, built live from that run's data.

Want the dashboard again later without re-running everything? Just double-click `dashboard/index.html`, or run `python 05_generate_dashboard.py`.

## What it does

```
Raw CSVs
   ↓
Bronze  — ingests raw files, adds ingestion metadata (Databricks Autoloader)
   ↓
Silver  — cleans, dedupes, casts types, runs SCD Type 2 on suppliers
   ↓
Gold    — 6 business KPI tables
   ↓
Dashboard (local HTML) + Power BI (production)
```

**6 raw datasets:** products, suppliers, inventory, warehouse, orders, sales

**6 Gold KPI tables:**
- `inventory_snapshot` – stock + value per product/warehouse
- `low_stock_alerts` – what's below reorder threshold
- `supplier_performance` – on-time %, delays, ratings
- `product_movement` – fast/medium/slow movers
- `sales_summary` – revenue & units by warehouse/category
- `sales_trends` – monthly revenue trend

The dashboard (`dashboard/index.html`) is generated by `scripts/05_generate_dashboard.py`, which reads the Gold CSVs and builds the whole thing from real numbers — nothing hardcoded. Change the data, re-run the pipeline, dashboard updates.

Screenshots of a real run are in `screenshots/`, and every script can be run on its own too, in order: `01 → 02 → 03 → 04 → 05`.

## SCD Type 2, briefly

The suppliers table tracks history instead of overwriting it. When a supplier's address or rating changes, the old row gets closed out (`is_current = False`) and a new row opens — so past reports still reflect what was true at the time. Done with a pandas comparison loop locally, and a proper Delta `MERGE INTO` in the Databricks version.

## Deploying the real thing on Databricks

1. Create an ADLS Gen2 storage account with `raw`, `bronze`, `silver`, `gold` containers.
2. Upload the 6 CSVs into `raw/<table_name>/`.
3. Spin up a cluster (or use the job cluster in `job_config.json`).
4. Run the notebooks in order: `01_bronze_autoloader` → `02_silver_transform_scd2` → `04_data_quality_checks` (optional) → `03_gold_kpis`.
5. Import `job_config.json` into Databricks Workflows to schedule it daily.
6. Connect Power BI to the Databricks SQL endpoint, point it at the `gold` schema.
